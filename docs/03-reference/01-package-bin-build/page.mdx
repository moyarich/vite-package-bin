# API reference: `packageBinBuild`

Import `packageBinBuild` from `@moyarich/vite-package-bin` and add it to `plugins` in `vite.config.ts`.

| Option | Type | Default / behavior |
| --- | --- | --- |
| `entries` | `PackageBinEntry \| PackageBinEntry[]` | `src/**/*.ts` and `src/cli/**/*.sh` |
| `sources` | `Record<string, string>` | Explicit command-name → source-path mappings; otherwise basename discovery |
| `emptyOutDir` | `boolean` | Required |
| `outDir` | `string` | `bin` |
| `target` | `string` | `node24` |
| `sourcemap` | `boolean` | `false` |
| `minify` | `boolean` | `false` |
| `external` | `Array<string \| RegExp>` | `[]`; `node:` dependencies always externalized |
| `validate` | `boolean` | `true` |

`PackageBinEntry` has `pattern: string` and optional `bin?: string`; `{name}` in the template is replaced by the source basename.

### Exports

- `packageBinBuild(options)` — Vite plugin coordinating builds and copying shell bins.
- `readManagedPackageBins(root?)` — read and normalize manifest `bin` declarations.
- `discoverCliEntries(entries?, root?, bins?, defaultBinPattern?, sources?)` — resolve entry paths.
- `standaloneCliBuilds(entries, options?, root?, bins?)` — produce one Vite config for each Node command.
- `copyShellCliEntries(entries, bins, root?)` — copy and chmod shell executables.
- `validatePackageBins(bins, root?)` — check existence, executable bit, and shebang.

Node output extensions: `.js`, `.mjs`, `.cjs`. Shell outputs: `.sh`. Each destination must be within the package root, and all destinations must be inside `outDir` when `emptyOutDir` is enabled.

Each Node CLI is bundled independently; shared chunks are not supported for package-bin builds.
