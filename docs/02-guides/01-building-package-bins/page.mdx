# Building package bins

Every `package.json#bin` command maps to exactly one source. Use explicit `sources` if names do not match.

```json
{
  "bin": {
    "tool": "./dist/bin/tool.mjs",
    "check-dist": "./dist/bin/check-dist.mjs"
  }
}
```

```ts
import { defineConfig } from "vite";
import { packageBinBuild } from "@moyarich/vite-package-bin";

export default defineConfig({
  plugins: [
    packageBinBuild({
      emptyOutDir: true,
      outDir: "dist/bin",
      sources: {
        tool: "src/commands/main.ts",
        "check-dist": "src/commands/check-dist.ts",
      },
      external: ["commander"],
    }),
  ],
});
```

`external` keeps a dependency out of the generated bundles. Make sure the consumer package provides that dependency at runtime.

## Name-based discovery

Without `sources`, command names are matched against source basenames through configured `entries`. Narrow glob patterns when helper files or duplicate basenames could otherwise be included.

```ts
packageBinBuild({
  emptyOutDir: true,
  outDir: "dist/bin",
  entries: [{ pattern: "src/commands/**/*.ts" }],
});
```

Name-based discovery expects the template destination `./dist/bin/{name}.mjs` in this example. Use explicit `sources` for custom output paths.

## Shell commands

Shell scripts are copied rather than bundled. They need an existing shebang such as `#!/usr/bin/env bash`, and a matching `.sh` bin path. See [examples](../../../examples/README.md).

## Output validation

The plugin sets execute permissions and validates each declared output by default. The `emptyOutDir` option clears the configured directory before rebuilding; all bin destinations must be under that directory. Separate Node entry points each produce a standalone bundle—there is no cross-command shared-chunk output.

## Troubleshooting

- **No source matched:** Provide a `sources` entry for the bin or correct the discovery patterns and `bin` paths.
- **Source collision:** Narrow `entries` or explicitly map the command using `sources`.
- **Missing shebang:** Add one to shell sources; Node executables are given a Node shebang automatically.
- **Unexpected distribution path:** Check the exact value of `package.json#bin`.
